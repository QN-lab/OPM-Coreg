# OPM-Coreg

OPM-Coreg is an open-source graphical user interface (GUI) for co-registering Optically Pumped Magnetometer (OPM) sensors and auxiliary devices with anatomical MRI data.

![OPM-Coreg GUI](docs/resources/opm_coreg_gui_screenshot.png)

## Installation

### Windows Installer

Download the latest release:

https://github.com/QN-lab/OPM-Coreg/releases

### PyPI

```bash
pip install opm-coreg
```

Launch the GUI:

```bash
opm-coreg
```

### Source Installation

```bash
git clone https://github.com/QN-lab/OPM-Coreg.git
cd OPM-Coreg
pip install -e .
```
